<div align="center">

## <img src="https://img.shields.io/badge/🌐_WHAT_IS_THIS-0A0A0A?style=for-the-badge&labelColor=107C10" />

</div>

The **official website** for **Jail X360** — the homebrew store for jailbroken Xbox 360 consoles.

This repo contains the full landing site, documentation pages, compatibility lists, roadmap, FAQ, and more — all built with plain HTML, CSS, and vanilla JavaScript, deployed free on **GitHub Pages**.

> ⚠️ **Jail X360 is not live yet.** The store is in development. This website is the public face of the project until launch.

<!--                        RUN LOCALLY                          -->
<!-- ═══════════════════════════════════════════════════════════ -->

<div align="center">

## <img src="https://img.shields.io/badge/💻_RUN_LOCALLY-0A0A0A?style=for-the-badge&labelColor=FF6B00" />

</div>

Clone the repo and open `index.html` in your browser — that's it. No build step, no dependencies.

```bash
# Clone the repo
git clone https://github.com/Frosty-Dev-Xbox/Jail-X360-Web.git
cd Jail-X360-Web

# Option 1: Just open it
open index.html

# Option 2: Serve locally (recommended for testing pages/)
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## <img src="https://img.shields.io/badge/🚀_DEPLOYMENT-0A0A0A?style=for-the-badge&labelColor=107C10" />

</div>

This site **auto-deploys** to GitHub Pages via the workflow in `.github/workflows/deploy.yml`.

**One-time setup:**
1. Go to **Settings → Pages**
2. Under **Build and deployment → Source**, select **"GitHub Actions"**
3. Done — every push to `main` deploys automatically

**Live URL:** `https://frosty-dev-xbox.github.io/Jail-X360-Web`
