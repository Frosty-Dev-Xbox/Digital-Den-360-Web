## 💗 What Is Digital Den 360?

**Digital Den 360** is a homebrew store for jailbroken Xbox 360 consoles. Browse and download **games, emulators, utilities, and themes** directly to your console — no PC required.

> ⚠️ **Not live yet.** Digital Den 360 is in development. Star the repo to get notified when the beta drops.

---

## ✨ Features

| Feature | Description |
|:---|:---|
| 🎮 **Homebrew Games** | Shooters, platformers, fighters, puzzle games |
| 🕹️ **Emulators** | NES, SNES, Genesis, N64, and more |
| 🛠️ **Utilities** | Dashboards, tools, patches, save editors |
| 🎨 **Themes** | Custom dashboard skins |
| 📦 **One-Click Install** | Straight to console, no PC |
| 🔄 **Auto-Updates** | Manifest stays fresh |

## 🚀 Install (Once Beta Drops)

1. Add the Digital Den 360 manifest URL to Aurora
2. Launch from your scripts menu
3. Browse the catalog
4. Hit download — installs to your console

## 📜 Legal

Digital Den 360 only hosts **homebrew and open-source content**.
No retail games. No XBLA. No piracy. Ever.
